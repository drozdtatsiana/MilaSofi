# MilaSofi

Адаптивный сайт салона красоты MilaSofi. Учебный проект для портфолио.

🔗 **[Открыть сайт](https://drozdtatsiana.github.io/MilaSofi/)**

![Скриншот сайта MilaSofi](main.png)

## О проекте

Одностраничный сайт с описанием услуг салона (парикмахерские услуги, детские и мужские стрижки, перманентный макияж), блоком о мастере, галереей работ и информацией об оплате.

## Что реализовано

- адаптивная вёрстка по макету (десктоп, планшет, телефон)
- слайдер с работами на Swiper
- модальное окно
- оптимизация изображений: AVIF, WebP и сжатые JPG
- SVG-спрайт для иконок
- локальные шрифты

## Технологии

- HTML5, семантическая вёрстка
- SCSS, методология БЭМ
- JavaScript
- Swiper
- Gulp 4: сборка страниц, стилей, скриптов, изображений и спрайтов

## Запуск проекта

```bash
git clone https://github.com/drozdtatsiana/MilaSofi.git
cd MilaSofi
npm install
gulp
```

Сайт откроется на http://localhost:3000

Сборка для публикации:

```bash
gulp build
```
